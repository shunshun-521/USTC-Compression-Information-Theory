# 极化码编译码仿真实验报告

## 1. 实验概述

本实验在 AWGN 信道下实现极化码的 GA 构造、SC/SCL/BP 译码与蒙特卡洛 BLER 仿真，码率 \(R=0.5\)，设计 SNR 为 \(E_b/N_0=2.5\,\text{dB}\)。

**仿真说明（快速模式）**：受 Cloud Agent 环境时长限制，实验二、三采用 `POLAR_QUICK=1` 参数：`E_b/N_0 \in \{2.0,2.5,\ldots,5.0\}\,\text{dB}\)（步长 0.5 dB，共 7 点），每点最多 4000 帧、至少 40 个块错误。实验一使用完整 22 个 SNR 点（步长 0.25 dB）。报告结论基于上述数据，完整 18 点/50000 帧仿真可在本地服务器补跑。

---

## 2. 实验一：SC 译码基础仿真

### 2.1 构造与冻结集

- 采用 **GA（高斯近似）** 构造，在 \(E_b/N_0=2.5\,\text{dB}\) 下得到 LLR 均值序列，按**比特倒序域**选取最可靠 \(K\) 个位置为信息集 \(\mathcal{A}\)。
- 信息集与冻结集已输出至 `results/frozen_sets.txt`（含 N=256/512/1024）。
- 冻结向量：信息位为 0，冻结位为 1。

### 2.2 SC 译码器

- 实现非递归 SC 译码（对数域 box-plus），预计算 `lambda_offset`、`llr_layer_vec`、`bit_layer_vec`。
- 单元测试：\(u=[1,0,1,1] \Rightarrow x=[1,1,0,1]\)；N=64 无损帧校验通过。

### 2.3 仿真结果

| 码长 N | 最低测得 BLER（约） | 对应 \(E_b/N_0\) |
|--------|---------------------|------------------|
| 256    | \(\sim 10^{-4}\)    | 4.75 dB          |
| 512    | \(\sim 10^{-4}\)    | 3.5 dB           |
| 1024   | （见 CSV）          | —                |

- 曲线见 `results/fig1_sc_bler.png`，含 BPSK-AWGN 香农限竖线（\(R=0.5\) 时约 **0 dB**）。

### 2.4 与 Shannon 限差距

- 低 SNR（\(<2\,\text{dB}\)）：BLER 接近 0.1–1，远离容量。
- 中 SNR（2–3 dB）：N=512 的 BLER 从 \(\sim 0.1\) 降至 \(\sim 5\times 10^{-3}\)，仍比 Shannon 限高约 **2–3 dB** 量级（有限码长 + SC 次优）。
- 高 SNR（\(>4\,\text{dB}\)）：BLER 可至 \(10^{-4}\) 量级，曲线斜率变缓，体现有限 \(N\) 的误差地板趋势。

## 3. 实验二：SCL 译码及 CRC 辅助

### 3.1 配置

- \(N=512,\,K=256,\,R=0.5\)，与实验一相同 \(\mathcal{A}\)。
- 列表大小：\(L \in \{1(\text{SC}),2,4,8\}\)；另含 **CA-SCL**（\(L=8\)，CRC-8）。L=16 未纳入本次快速模式仿真。

### 3.2 BLER 性能

- **列表增益**：\(L=2\to 4\to 8\) 在中等 SNR（2–3 dB）BLER 明显下降，\(L=8\) 后增益趋于饱和（符合预期）。
- **CA-SCL**：CRC 筛路径后在同一 \(L=8\) 下进一步降低 BLER，高 SNR 下可接近 0。
- 曲线见 `results/fig2_scl_bler.png`。

### 3.3 译码复杂度

- 平均单帧译码时间随 \(L\) **近似线性增长**（SC \(\sim 10\,\text{ms}\) → SCL L=8 \(\sim 80\,\text{ms}\)）。
- 柱状图见 `results/fig2_decode_time.png`。
- 结论：**列表越大性能越好，但复杂度与 \(L\) 近似成正比**；工程上需在 BLER 与延迟间折中。

## 4. 实验三：BP 译码

### 4.1 实现

- BP 译码器基于 **Sionna PolarBPDecoder**（sum-product / box-plus，max_iter=50）。
- 修复说明：原 min-sum 因子图实现与信道 LLR 符号约定不一致，导致 BLER≈1；现采用与 SC 相同的 `compute_llr` 接口，内部完成 Sionna logits 转换。

### 4.2 仿真结果（N=256, 512）

- **BP vs SC**：在中等 SNR 下 BP 通常**劣于 SC**（极化码 BP 存在短环，置信传播易陷入伪码字）；增益并非来自译码顺序，而是迭代消息传递对软信息的利用，但受限于图结构。
- **BP vs SCL**：SCL 明显优于 BP；码长从 256→512 时，SC/SCL 增益随 \(N\) 增加，BP 与 SCL 差距**相对扩大**（SCL 更接近 ML，BP 仍受迭代与图结构限制）。
- BLER 对比见 `results/fig3_bp_N256_bler.png`、`fig3_bp_N512_bler.png`。
- BP 平均迭代次数见 `fig3_bp_N*_iters.png`（高 SNR 早停时迭代更少）。

### 4.3 BER

- CSV 中同时记录 BER；趋势与 BLER 一致，BP 的 BER 通常高于 SC/SCL。

## 5. 三种算法对比与结论

| 算法 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **SC** | 复杂度 \(O(N\log N)\)，实现简单，低延迟 | 有限码长下距 Shannon 限有 gap | 低延迟、资源受限 |
| **SCL** | 显著优于 SC，可近 ML；CA-SCL 进一步提升 | 复杂度 \(\propto L\)，存储路径 | 5G/eMBB 等高性能需求 |
| **BP** | 可迭代、便于与 LDPC 等统一框架 | 极化码上性能通常不如 SC/SCL；迭代多 | 研究/联合译码，短码或特殊图结构 |

**总结**：

1. GA 构造 + SC 可完成基础 BLER 曲线，随 \(N\) 增大性能改善。
2. SCL 列表增益在 \(L=8\) 附近开始饱和；CA-SCL 用 CRC 换性能，代价可忽略。
3. BP 在本实验参数下**不能替代 SC/SCL**，但完成了手册要求的第三种译码对比。
4. 快速模式结果用于趋势分析与报告；若需论文级误差点，建议在本地补跑完整蒙特卡洛并 commit CSV。
